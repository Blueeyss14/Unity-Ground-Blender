# Ground Blender URP

Ground Blender URP tool for Unity. Seamlessly blend 3D objects into ground/terrain shaders in Universal Render Pipeline.

## How to Install via Unity Package Manager (Git URL)

1. Open your Unity Project (URP compatible).
2. Go to **Window** > **Package Manager**.
3. Click the **+** (plus) icon in the top left corner.
4. Select **Add package from git URL...**
5. Enter the GitHub repository URL:
   ```text
   https://github.com/Blueeyss14/Unity-Ground-Blender.git
   ```
6. Click **Add**. Unity will automatically download and install the package.
